# PIAT Academic Management System

## Overview

This repository contains the PIAT Academic Management System, a multi-platform academic operations project with:

- a web frontend powered by Vite and React
- a Node/Express backend with a SQLite database
- a mobile Expo client for attendance and mobile workflows

## Repository structure

- `frontend/` — web application source, public assets, HTML entry, and TypeScript configuration
- `backend/` — REST API, backend modules, scripts, and tests
- `database/` — tracked SQLite databases and database backups used by the backend
- `mobile_build/` — Expo mobile attendance application
- `docs/` — architecture, schema, and system documentation
- `docs/reports/` — functional, security, and codebase review reports
- Root-level Vite, ESLint, Playwright, and Wrangler files — shared project/tooling configuration

The preserved review reports are in [`docs/reports/`](./docs/reports/).

## Quick start

1. Install root dependencies:
   ```bash
   npm install
   ```
2. Start the backend service:
   ```bash
   cd backend
   npm install
   ```
   Create `backend/.env` from `backend/.env.example` and set `JWT_SECRET` to a random value of at least 32 characters. In PowerShell:
   ```powershell
   Copy-Item .env.example .env
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```
   Copy the generated value into `JWT_SECRET` in `.env`, then start the backend:
   ```bash
   npm start
   ```
3. Start the web frontend:
   ```bash
   cd ..
   npm run dev
   ```
4. Start the mobile app (optional):
   ```bash
   npm --prefix mobile_build install
   npm run mobile:start
   ```

## Backend and data seeding

- The backend uses SQLite and defaults to `database/piat.db`. Set `PIAT_DB_PATH` to override the path. For compatibility, an existing `backend/piat.db` is preferred when present.
- Faculty evaluations are a native PIAT feature backed by SQLite. See [the faculty evaluation guide](./docs/FACULTY_EVALUATIONS.md) for administration, API, privacy, and testing details.
- The relational system-test dataset can be seeded using:
  ```bash
   npm run seed:test
  ```
- This creates 200 marked student records, accounts, curriculum-backed offerings, enrollments, grades, attendance, notifications, and academic history. Use `npm run seed:test:reset` to regenerate it safely.
- All mock student accounts use the password `PiatTest2026!`; the generated report is written to `MOCK_DATA_TEST_REPORT.md`.

## Notes

- The backend API runs on `http://localhost:4000` by default.
- The web frontend should proxy API requests to the backend.
- The mobile app requires a running backend and properly configured API base URL.
- The `.expo` folder is generated by Expo and should not be committed.
